# ЮТУБЕРЫ

Инкрементальная игра про ютубера: снимай, монтируй, загружай, покупай технику и нанимай команду, пока не наберёшь 1 000 000 подписчиков.

## Как запустить
Откройте `index.html` в браузере (двойной клик). Интернет нужен только для шрифтов.

Управление: кнопки или клавиши `1` (съёмка), `2` (монтаж), `3` (загрузка).
Прогресс сохраняется в браузере автоматически.

## Файлы
- `index.html` — интерфейс, графика комнаты, тексты RU/EN.
- `logic.js` — правила и баланс игры (без интерфейса). Числа баланса в начале файла.
