# YouTube-трекер в Google Таблице: установка

Установка занимает около 5 минут и делается один раз. Удобнее с компьютера.

## 1. Создайте таблицу
Откройте **https://sheets.new** и назовите таблицу, например «YouTube ПОРОГ».

## 2. Откройте редактор скриптов
В меню таблицы выберите **Расширения → Apps Script**.

## 3. Вставьте код
Удалите всё, что есть в файле `Код.gs`, и вставьте весь текст из файла **`Code.gs`**. Сохраните (💾 или Ctrl+S).

## 4. Подключите сервисы YouTube
Слева, рядом с надписью **«Сервисы»**, нажмите **＋** и добавьте по очереди:
- **YouTube Data API v3** (идентификатор оставьте `YouTube`);
- **YouTube Analytics API** (идентификатор оставьте `YouTubeAnalytics`).

## 5. Первый запуск
1. Вверху, в списке функций, выберите **`setup`** и нажмите **▶ Выполнить**.
2. Google попросит разрешение: **Проверить разрешения**, затем выберите аккаунт.
   - Если канал «ПОРОГ» принадлежит аккаунту бренда, выберите именно его.
3. Появится предупреждение «Google не проверил это приложение». Это нормально, скрипт ваш. Нажмите **Дополнительно → Перейти на страницу (небезопасно) → Разрешить**.
4. Подождите 10–30 секунд.

## 6. Готово
Вернитесь в таблицу и обновите страницу. Там появятся:
- **Сводка** — общие цифры, количество видео по статусам, подсказки и топ-5 за неделю.
- **Видео** — все видео со статусами. Нажмите стрелочку в заголовке «Статус», чтобы показать, например, только 🔴.
- **История** — ежедневные снимки. Из них считается колонка «Прирост с прошлого обновления».

В таблице появится меню **📊 YouTube**: через него можно обновить данные вручную или включить/выключить ежедневное обновление. Таблица обновляется сама каждый день около 7:00.

## Что означают статусы
| Статус | Значит |
|---|---|
| 🆕 Новое | вышло меньше 7 дней назад, рано судить |
| 🚀 Растёт | за неделю на 20%+ больше просмотров, чем за прошлую |
| 🟢 Стабильно | примерно как на прошлой неделе (от −20% до +20%) |
| 🟡 Затухает | на 20–60% меньше |
| 🟠 Резко падает | больше чем на 60% меньше |
| 🔴 На стопе | меньше 50 просмотров за неделю |

Пороги можно поменять в начале файла `Code.gs`, в блоке «НАСТРОЙКИ».

## Если что-то не работает
- **«YouTube is not defined»**: не подключены сервисы, см. шаг 4.
- **«Канал не найден»**: при разрешении выбран не тот аккаунт. Запустите `setup` ещё раз и выберите аккаунт бренда.
- **Свежих цифр за сегодня и вчера нет.** YouTube отдаёт аналитику с задержкой около 2 дней. Колонка «Всего просмотров» при этом почти в реальном времени.
